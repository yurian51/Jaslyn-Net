# Mobile-money logos

Drop the official logo for each network here. Filenames are exact; `.svg` is preferred (then `.png`, `.webp`).
The landing page picks them up automatically; a missing file falls back to the network's name.

| Network | File |
|---|---|
| M-Pesa | `mpesa.svg` |
| Mixx by Yas | `mixx-by-yas.svg` |
| Airtel Money | `airtel-money.svg` |
| HaloPesa | `halopesa.svg` |
| AzamPesa | `azampesa.svg` |

Get the files from each network's own brand or press kit, and follow its usage terms. Use a transparent
background and the horizontal version of the logo (about 3:1) so every tile aligns.

For the Ruckus router logo, add `public/integrations/ruckus-logo.svg` (the existing `ruckus.svg` is plain text, not a logo).
